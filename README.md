# قالب دراسة الجدوى — عربي / English

قالب **دراسة جدوى** ثنائي اللغة بالعربية الفصحى والإنجليزية، مبنيّ بمنطق RTL/LTR أصيل،
مطبوع على مقاس A4، ومزوّد بمحرك مالي حيّ، ومولّد مستندات تنفيذية.

- **العربية:** `index.html` — RTL
- **English:** `en/index.html` — LTR

المشروع المرجعي في النسخة الحالية: **التوسّع في التجارة الإلكترونية لورشة نجارة قائمة**
(Dar Al-Khashab) — بمزيج «software house · marketing agency · AI agency».

---

## التشغيل

```bash
cd feasibility
python3 -m http.server 8000

# العربية   → http://localhost:8000/index.html
# English  → http://localhost:8000/en/index.html
```

> يعمل أيضًا بفتح `index.html` مباشرة (‎file://‎) بلا خادم — البيانات مضمّنة في
> `assets/data/project.js` و `assets/data/project-en.js`، وتُزامن تلقائيًّا مع ملفات
> JSON عند التشغيل عبر HTTP.

### تبديل اللغة داخل الصفحة

زر اللغة في شريط الأدوات ينقل بين النسخة العربية والإنجليزية، ويحفظ الاختيار في الرابط
(`?lang=en`). يمكن أيضًا فرض اللغة على أي نسخة عبر هذا المعامل.

### اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|---|---|
| `Ctrl/⌘ + P` | طباعة أو حفظ PDF |
| `Ctrl/⌘ + S` | حفظ التعديلات |
| `Ctrl/⌘ + E` | تصدير بيانات المشروع (JSON) |

## النسخة المدمجة في ملف واحد

```bash
python3 tools/build_standalone.py
# → out/feasibility-standalone.html   (≈1.1 MB)
```

**ملف واحد يحتوي كل شيء**: الأنماط والخطوط (base64) والشيفرة وطبقتا البيانات.
يُفتح بالنقر المزدوج — بلا خادم، بلا إنترنت، بلا تثبيت — ويبقى **تفاعليًّا بالكامل**:
المحرك المالي الحيّ، الرسوم، تحرير الافتراضات، تصدير CSV/JSON، الاستيراد،
تبديل اللغة والسمة والأرقام، والطباعة إلى PDF.

| | |
|---|---|
| الحجم | ≈ 1.1 MB |
| المراجع الخارجية | **صفر** |
| يعمل من `file://` | ✓ (مُختبَر: 57 صفحة عربي / 62 صفحة إنجليزي) |
| تبديل اللغة داخل الملف | ✓ عربي ⇄ English (كل النصوص، لا البيانات فقط) |

> **الفصل بين النسختين في التخزين المحلي**: حالة التعديلات تُحفظ تحت مفتاح مستقل لكل لغة،
> فتعديل النسخة العربية لا يُسقط تعديلات النسخة الإنجليزية.

```bash
python3 tools/export_pdf.py              # القالبان: عربي + English
```

الأداة تشغّل خادمًا محليًّا مؤقتًا ثم تطبع عبر **Chrome DevTools Protocol**

**جاهزية الخطوط** (`document.fonts.ready`) — فتُضمَّن الخطوط داخل الملف النهائي
ويصبح الناتج **حتميًا** (نفس عدد الصفحات في كل تشغيل).

| الملف | الصفحات | المحتوى |

### تعديل المشروع

1. عدّل `assets/data/project.json` (و `project-en.json` إن أردت النسخة الإنجليزية).
2. حدّث النسخ المضمّنة:

```bash
python3 tools/generate_docs.py --sync
```

3. أعد تحميل الصفحة.

> إن استعملت المتصفح عبر HTTP فإن القالب يقرأ ملفات JSON مباشرة ويُحدّث نفسه تلقائيًّا.

### بناء النسخة الإنجليزية

```bash
python3 tools/build_en.py         # project.json → project-en.json (+ النسخة المضمّنة)
python3 tools/build_en_html.py    # index.html → en/index.html
```

الترجمة تُدار من قاموسين: `tools/translations_en.py` (محتوى البيانات) و
`tools/translations_en_html.py` (نصوص القالب الثابتة). أي نص عربي جديد يظهر في
المخرجات الإنجليزية كمخرج «غير مترجم» مع مساره، فيُضاف إلى القاموس المناسب.

## المحرك المالي

يعمل داخل المتصفح ويحدّث النتائج فور تعديل أي مدخل:

| المُخرَج | طريقة الحساب |
|---|---|
| قائمة الدخل | إيراد − تكلفة مبيعات − مصروفات − إهلاك − ضريبة |
| التدفق النقدي | صافي الربح + الإهلاك − الاستثمارات − تغيّر رأس المال العامل |
| NPV | القيمة الحالية للتدفقات عند معدل الخصم |
| IRR | نيوتن مع تراجع آمن إلى bisection |
| فترة الاسترداد | simple و discounted |
| نقطة التعادل | ثابتة ÷ هامش المساهمة للوحدة |
| الحساسية | 6 متغيّرات (تورنادو) + جدول متقاطع (السعر × الحجم) |
| السيناريوهات | متحفظ / أساسي / متفائل |

**ملاحظات على الافتراضات:**
- `growth` في مصادر الإيراد **نسبة مئوية** (‎`12`‎ تعني 12% وتُحوَّل داخليًّا).
- `year: 0` في بنود CAPEX يعني **الاستثمار الأولي** (بلا خصم زمني).
- `type: "pct_revenue"` في OPEX يعني بندًا **نسبةً من الإيراد** (لا مبلغًا ثابتًا).

### التصدير

- زر **«تصدير CSV»** في رأس كل جدول (بقيم خام تصلح لـExcel).
- زر **«النموذج المالي»** يُصدر `CSV` + `JSON` يحويان الافتراضات والنتائج والسنوات والسيناريوهات.

## مبادئ RTL / LTR المطبَّقة

| المبدأ | التطبيق |
|---|---|
| اتجاه الصفحة | `<html lang="ar" dir="rtl">` / `<html lang="en" dir="ltr">` |
| المسافات | خصائص **منطقية** فقط: `margin-inline-start`، `inset-inline-end`، `border-inline-start` — ولا `left/right` في أي مكان |
| النص | `text-align: start/end` تلقائيًّا مع الاتجاه |
| الخط | `IBM Plex Sans Arabic` (عربي) و `IBM Plex Sans` (لاتيني) + `IBM Plex Mono` — **محليًّا** |
| تباعد الحروف | **صفر** على كل النصوص العربية (التباعد يقطع وصل الحروف) |
| ارتفاع السطر | `1.92` للمتن العربي / `1.68` اللاتيني، مع مساحة إضافية للنوات والصواعد |
| الأرقام | غربية افتراضيًا + زر تبديل إلى العربية الهندية (٠١٢٣)، والتواريخ تتبع لغة الوثيقة |
| العملة والنصوص المختلطة | عزل بـ `<bdi>` + `unicode-bidi: isolate` |
| الجداول | ترتيب الأعمدة حسب الاتجاه، `tabular-nums`، رؤوس متكرّرة عند الطباعة |
| الرسوم | المحاور الزمنية من اليسار لليمين (الإجماع في التقارير المالية)، والأشرطة الفئوية تتبع اتجاه الصفحة |

## الطباعة

- مقاس **A4**، هوامش `24 / 15 / 18 مم`.
- كل قسم رئيسي يبدأ **صفحة مستقلة**.
- **ترويسة وتذييل متكرران** في كل صفحة، والتذييل يحمل رقم الصفحة (`counter(page)`).
- الجداول تُطبع بأحجام مخفّضة مع `table-layout: fixed` فلا تتجاوز عرض الصفحة.
- البطاقات والرسوم لا تُفصل عن صفحتها (`break-inside: avoid`).
- الجداول المالية مبنيّة **بالأعمدة** (بنود × سنوات) لتلائم الطباعة Portrait.

> **ملاحظة:** ترقيم الصفحات في المتصفح لا يُحسم إلا عند الطباعة نفسها؛ لذلك يعرض الفهرس
> **أرقام الأقسام**، وتظهر **أرقام الصفحات** في تذييل كل صفحة. وعند التصدير إلى PDF يولّد
> Chrome عناوين (Bookmarks) تلقائيًّا من العناوين.

## إمكانية الوصول

- رابط تخطٍّ إلى المحتوى، ومعالم دلالية، وتسلسل عناوين متدرّج.
- تباين ≥ 4.5:1 في السمة الفاتحة والداكنة.
- `focus-visible` ظاهر، و`aria-live` على النتائج المحسوبة.
- دعم `prefers-reduced-motion` و`prefers-color-scheme`.
- الحقول القابلة للتحرير موسومة بـ `label` و`aria` واضحة.

## نصائح للاستخدام مع عميل

1. **حدّد مؤشّرًا لكل وكيل.** الوكيل الذي لا يمكن قياس أثره تكلفةٌ لا أصل.
2. **اربط كل رقم بمصدر.** ما لا مصدر له تقدير يحتاج إلى اختبار.
3. **اجعل الشروط المعلقة قابلة للتحقق.** «تحسين التحويل» ليست شرطًا؛ «تحويل ≥ 1.4% خلال 45 يومًا» شرط.
4. **راجع النموذج بعد الشهر الثالث** واضبط الافتراضات على ضوء البيانات الفعلية.
5. **صدّر PDF واحتفظ بالـJSON** في أرشيف المشروع — هما نسختان من الحقيقة.
